- New: a settings screen, and the module now has a launcher icon again.
  The UI is written in Compose with Material 3 Expressive
  (MaterialExpressiveTheme + expressive motion, dynamic color on Android 12+).
- New: two icon modes to pick from in the UI.
  * "Colored launcher icon" (default): replace an unthemed notification icon
    with the app's own launcher icon, original colors kept.
  * "System monochrome": compress the app's own small icon into a monochrome
    silhouette and let the system tint it like every other notification.
- The module reads those settings from the app's SharedPreferences through
  LibXposed remote preferences (getRemotePreferences, API 102). If the
  framework does not advertise that capability, or the app was never opened,
  the module falls back to the previous built-in defaults and keeps working.
- Module description now mentions both modes (still 26 Chinese characters).
- scripts/check-device.sh no longer force-stops SystemUI. Force-stopping it
  makes WallpaperManagerService treat SystemUI as an uninstalled package and
  reset the wallpaper to the system default, so the script reboots instead.
