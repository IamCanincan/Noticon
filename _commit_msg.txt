fix: 给 application 加 android:description（Vector 里显示描述的真正字段）

用户反馈装了新版还是没描述，并给了能正常显示描述的参考应用。
用 aapt2 对比设备上两个「能显示描述」的模块，找到了真正的根因。

之前的结论是错的：以为 Vector 查的是 xposeddescription meta-data。
实际上 Vector 按模块的 Xposed API 版本走不同读取路径：

  | 模块类型                  | Vector 读的字段                    |
  |---------------------------|-----------------------------------|
  | 老 Xposed（minversion=93）| xposeddescription meta-data       |
  | LibXposed（API >= 100）   | android:description 属性          |

实测证据（aapt2 dump 设备上 pm path 拉出来的 APK）：

Global Icon Pack（minversion=93，能显示）：
  有 xposeddescription="Apply icon pack globally" meta-data
  没有 android:description

Eta（LibXposed API 102，能显示）：
  有 android:description=@string/xposed_description
  xposeddescription meta-data 数量为 0（完全没有）
  该资源的中文值正是界面上显示的文字：
    "系统级 AI Agent，接管小布与小爱，解锁 Gemini 与一圈即搜，
     集成浏览器、终端与设备工具"

Noticon（API 102）：之前只有 meta-data，没有 android:description
  → 完全解释了「一直显示空」

修复：application 标签加 android:description="@string/xposed_description"。
meta-data 保留做兼容（LSPosed / 老框架仍读它），两者不冲突。

注意：GitHub 上的源码目录可能跟设备上装的版本不一致
（global-icon-pack-android 源码 manifest 里没有任何 xposed meta-data，
但设备上装的 APK 里有）。诊断必须以 pm path 拉出来的 APK 为准。

验证：
  aapt2 dump xmltree 显示 application 有
    android:description(0x01010020)=@0x7f0b0009
  且 0x7f0b0009 = "把未适配主题的通知小图标..." 真实描述文字
  三个 xposed meta-data 也都还在（兼容）

设备已 install -r，重开 Vector 模块页即可看到描述。
