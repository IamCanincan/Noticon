fix: xposeddescription 字符串资源里存的是字面引用而非真实描述

用户截图：Vector 模块页面 Noticon 没有描述（Eta 和全局图标包都有描述）。

aapt2 dump resources 显示问题：
  resource 0x7f0b000a string/xposeddescription
    () @string/xposed_description   ← 字面字符串，未解析！

根因：strings.xml 里
  <string name="xposeddescription">@string/xposed_description</string>
  aapt2 对 `<string>X</string>` 元素值是 `@string/Y` 的情况处理有边界 bug，
  没解析引用而是存了字面字符串。
  Vector 反射 Resources.getString(R.string.xposeddescription) 拿到的是
  "@string/xposed_description" 字面量而非真实描述 → 显示「没有描述」。

修复：两个 string 资源（xposed_description 和 xposeddescription）都直接写
完整字符串，不互相引用。改文字需要改两处，但避开了 aapt2 bug。

已记入项目记忆强化版：
- `aapt2 dump resources app.apk | grep string/xposed` 验收链
  应该看到 `() "真实描述"` 而不是 `() @string/xposed_description`

诊断依据（已记入记忆但本次用上）：
- Vector 实际查找的资源名是 `xposeddescription`（无下划线），不是 LSPosed 标准的 `xposed_description`
- meta-data 必须用字符串字面量，不能写 `@string/xxx`（这次 manifest 是对的）
- R8 资源裁剪会删没人引用的 string 资源，必须 keep.xml（这次 keep.xml 是对的）

打包+安装：APK 已签名并 install -r，Vector 下次打开会重新读取。
