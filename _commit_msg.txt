release: 1.0.2

版本号 1.0 → 1.0.2（versionCode 1 → 2），并整理仓库。

本次版本包含的改动（自上一个版本以来）：

模块形态
- 改成纯 LibXposed API 102 模块：删掉 manifest 里全部老式 meta-data
  （xposedmodule / xposeddescription / xposedminversion / xposedscope）与
  它们依赖的 arrays.xml、keep.xml。
  模块名走 android:label，描述走 android:description，
  作用域走 META-INF/xposed/scope.list，配置走 module.prop。
- module.prop 补上 staticScope=true：管理器只列出 scope.list 里写死的
  com.android.systemui，不允许把模块用到别的应用上。
- 模块描述缩短到 26 字，避免列表里占好几行。

代码修复
- SystemUiHooks：setIcon / updateIconColor / processSmallIconColor 补上按 id 的
  重复安装判重（框架对同一进程会回调 onPackageReady 数次，之前这三条各被装了
  多遍，日志里出现 10 行 hooked 而不是 4 行）。
- IconBitmap.applySmallIcon 改为返回 Boolean：反射写 mSmallIcon 失败时不再
  打印假的 patched 成功日志（patched 是排查时唯一的"真的换了"凭据）。
- ModuleOptions：删掉 LAUNCHER_ICON_MONOCHROME 上错误的"（默认）"标注。

工具与文档
- scripts/check-device.sh：adb 端口可配（默认 5039，5037 在部分 Windows 上
  落在系统保留端口段内），重启 SystemUI 改用 am force-stop（kill 会
  Operation not permitted），去掉"勾选作用域"的过时提示。
- README 同步更新：安装步骤、排查命令、作用域说明、APK 文件名。
- .gitignore 补 .kotlin/；metadata 里 API 100+ 统一为 102。
- 新增 metadata/en-US/changelogs/2.txt。

仓库整理
- 清掉历史遗留：提交信息里出现的参考项目名与本地路径已全部泛化替换
  （git log 全库检索为 0），备份分支与 filter-branch 残留已清除并 gc。

产物：Noticon-v1.0.2-release.apk（55K，已签名、已装到真机）
